# Awesome-Applicant-Assessment-Platform

## Top Applicant Assessment Platform Ecosystem



**Curated List of SaaS Products & Open-Source GitHub Projects**  

*Focused on Skills Testing, Cognitive & Personality Assessment, Coding Challenges, Pre-Employment Screening & Talent Evaluation*  

**Last updated: September 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Applicant Assessment**. These systems help employers evaluate candidates through skills tests, cognitive assessments, coding challenges, situational judgment, and structured scoring—before or during the interview process.



**Examples** include TestGorilla, Criteria Corp, Harver, Testlify, Vervoe, HiPeople, Mercer Mettl, eSkill, Adaface, and Wonderlic (the category leaders).



**Open-source emphasis**: Full psychometric assessment suites are largely commercial. Open options are strongest for **coding assessments** (CoderScreen, CodeGaze, Judge0) and general exam/quiz platforms adaptable to hiring. This section lists every significant relevant project found.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms



- **[TestGorilla](https://www.testgorilla.com/)**  

  Popular skills-testing platform with a large library of role-specific, cognitive, and personality tests for pre-employment screening.



- **[Criteria Corp, Wonderlic](https://www.criteriacorp.com/)**  

  Established assessment providers focused on cognitive ability, aptitude, and predictive hiring science.



- **[Harver, Vervoe, HiPeople](https://harver.com/)**  

  Modern talent assessment platforms combining skills, situational judgment, and experience-based evaluation.



- **[Testlify, Adaface, eSkill](https://testlify.com/)**  

  Skills and coding assessment platforms with customizable tests and automated scoring for technical and non-technical roles.



- **[Mercer Mettl](https://mettl.com/)**  

  Enterprise assessment suite for hiring, workforce skilling, and certification at scale.



- **[Other commercial applicant assessment platforms](https://www.testgorilla.com/)**  

  Additional solutions for video assessments, game-based testing, and integrated ATS scoring.



## Open-Source GitHub Projects



- **[CoderScreen](https://github.com/CoderScreen/coderscreen)**  

  Modern open-source technical hiring platform—live coding interviews, auto-graded assessments, take-homes, and multi-language sandboxed execution; fully self-hostable.



- **[CodeGaze](https://github.com/hb1998/CodeGaze)**  

  Open-source coding screening platform—custom challenges, test cases, exams, and candidate invitations with automated scoring (pairs with Judge0).



- **[Judge0](https://github.com/judge0/judge0)**  

  Open-source online code execution system used as the engine behind many coding assessment products—secure sandboxed runs for dozens of languages.



- **[RecruitEm](https://github.com/nikolap994/recruit_em)**  

  Open-source exam system for hiring, testing, and certifications—positions, questionnaires, candidate history, and reusable tests.



- **[Moodle / LimeSurvey for structured tests](https://github.com/moodle/moodle)**  

  Mature open learning and survey platforms frequently adapted for knowledge tests, quizzes, and structured applicant questionnaires.



- **[BigBlueButton / live interview open stacks](https://github.com/search?q=coding+interview+platform+open+source)**  

  Community projects combining video, collaborative editors, and scoring for remote technical interviews.



- **[Psychometric open datasets & scoring scripts](https://github.com/search?q=cognitive+test+OR+personality+assessment+open+source)**  

  Research-oriented open tools for cognitive and personality scoring (use only with proper validation and legal review).



- **[ATS + assessment connector projects](https://github.com/search?q=applicant+tracking+assessment+open+source)**  

  Open integrations that push assessment results into hiring pipelines.



### Additional Strong Open-Source Options



- **Technical hiring**: CoderScreen and CodeGaze + Judge0 for coding screens and live interviews.

- **General exams**: RecruitEm or Moodle for knowledge and questionnaire-based screening.

- **Composable stacks**: Open quiz/coding engine → score API → ATS webhook.

- Commercial platforms still lead in validated psychometric libraries, anti-cheating, and global norm groups.



**Frameworks for building custom systems**:  

**Judge0** + **CoderScreen/CodeGaze** for technical assessment; **RecruitEm** or **Moodle** for broader testing.  

Commercial platforms (TestGorilla, Criteria, Harver, Mettl, Adaface, etc.) provide validated test libraries and enterprise workflows.  

Engineering-heavy teams often self-host coding assessments and use commercial tools for cognitive/personality batteries. Fully open stacks work for technical screening; validated psychometrics usually require commercial or licensed instruments.

## Disclaimer



- This is a **community-curated** list — not exhaustive and not an endorsement.

- Pre-employment assessments can raise adverse-impact and fairness issues. Use only validated instruments where required, monitor outcomes by demographic group, and comply with EEOC, GDPR, and local employment law. Automated scores should not be the sole basis for hiring decisions.

- Open-source tools offer control but are generally not substitutes for professionally validated psychometric tests. Commercial platforms shift validation and support burden to the vendor. Involve legal and I/O psychology expertise for high-stakes hiring.
